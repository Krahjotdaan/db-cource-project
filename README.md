# Сервис онлайн-спорта

## О проекте

Разработана база данных для сервиса онлайн-тренировок по подписке. Система хранит информацию о пользователях, их подписках с историей изменений, тренировках и просмотрах. Реализованы механизмы контроля качества данных и аналитические запросы для оценки удержания пользователей и популярности тренировок.

## Данные

- 5 000 пользователей (95% имеют подписки)
- 70 тренировок, 30 тренеров, 15 типов тренировок
- 8 000 сессий занятий
- ~15 000 подписок с историей (SCD2)
- 100 000 логов просмотров (только в период активной подписки)

**Распределение просмотров:**
- 60% — досматривают почти до конца
- 30% — бросают на середине
- 10% — открывают и сразу закрывают
- 5% — пересматривают фрагмент (до 110% длительности)

## Механизмы качества

### Триггер валидации
Проверяет корректность email и телефона при вставке/обновлении пользователей. Невалидные данные отклоняются с ошибкой.

### SCD2 для подписок
Хранится полная история подписок каждого пользователя. Процедура загрузки проверяет:
- Даты не перевёрнуты
- Дата начала не в прошлом
- Отсутствие пересечений с существующими подписками

Загрузка через служебную таблицу.

## Аналитические запросы

### 1. Удержание пользователей
Определяет статус каждого пользователя:
- **Active** — подписка активна
- **Retained** — подписка закончилась менее 45 дней назад или есть следующая
- **Churned** — подписка закончилась давно
- **No Subscriptions** — никогда не подписывался

### 2. Популярность тренировок
Считает количество просмотров и средний процент досмотра для каждой тренировки.

## Индексы

Создан один покрывающий индекс на таблице подписок `(user_id, valid_from, valid_to DESC)`. Он позволяет выполнять аналитический запрос без обращения к самой таблице.
